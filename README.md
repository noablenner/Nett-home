# Nett'home

Site vitrine de **Nett'home**, entreprise locale de nettoyage, débarras et vitrerie
basée à Schlierbach, intervenant en Alsace et à Belfort.

## Aperçu

Site statique d'une seule page (`index.html`), sans dépendance à installer :
il suffit d'ouvrir `index.html` dans un navigateur.

### Points forts de la refonte
- Design moderne, dynamique et responsive (mobile, tablette, desktop)
- Reprise des couleurs du logo (bleu marine + bleu ciel)
- Comparateurs **avant / après** interactifs (curseur à glisser) sur les réalisations
- En-tête flottant, animations au défilement, bouton « Demander un devis » flottant
- Formulaire de contact qui prépare un email vers `nett.home68@gmail.com`

## Structure

```
index.html        # la page complète (HTML + CSS + JS intégrés)
assets/
  logo.jpg        # logo Nett'home
  tom.jpg         # photo du gérant, Tom Podgora
  avant-1..4.jpg  # photos "avant" des chantiers
  apres-1..4.jpg  # photos "après" des chantiers
```

## Mise en ligne

Compatible **GitHub Pages** : activer Pages sur la branche souhaitée,
la racine du dépôt sert directement `index.html`.
